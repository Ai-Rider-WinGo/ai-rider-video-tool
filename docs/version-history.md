# AI-Rider 版本历史

**中文** | [English](./version-history.en.md)

## 1.x 系列

`1.x` 是 AI-Rider 从本地工具走向正式产品雏形的阶段。结合前面对话和关键节点，原先笼统记录为 `1.0.0` 的内容，现重新整理为以下版本序列。

### 1.0.0

- 跑通本地 Web 版首尾帧生成基础流程
- 明确产品方向：围绕“首帧 + 尾帧 + 提示词”的视频生成工作流
- 建立前后端联调、任务创建、轮询、下载的基础能力

### 1.0.1

- 完成桌面端环境安装方案
- 安装 Electron 与打包依赖
- 增加桌面入口、环境检查脚本、桌面启动命令

### 1.0.2

- 完成品牌确认
- 产品名确定为 `AI-Rider｜首尾帧生成视频工具`
- 接入 LOGO、桌面图标、窗口标题、页面标题

### 1.1.0

- 完成第一轮核心体验升级
- 视频时长最小值调整为 `4 秒`
- `FPS` 默认值设置为 `30`
- 增加中英文切换
- 增加镜头提示预设
- 额外参数改为折叠隐藏项

### 1.1.1

- 进入标题栏和工具条专项优化阶段
- 增加 compact 顶栏
- 增加下载目录入口、任务状态数量
- 增加主题切换与语言入口整合

### 1.1.2

- 完成 H5 响应式适配
- 修复标题栏在小屏设备上的高度问题
- 优化 tooltip 越界、换行和边界显示
- 调整开关样式与配置项说明体验

### 1.1.3

- 完成 1.x 收尾与发布准备
- 整理版本文案、发布海报
- 完成版本结构化沉淀
- 作为 `2.0.0` 开始前的最终稳定版本

详细记录：

- [1.x 版本档案](./versions/1.0.0.md)

## 2.x 系列

`2.x` 是 AI-Rider Video 从单一桌面工具升级为产品体系化结构的阶段。核心方向包括多模型、多 API、激活码机制、Web 兼容和 AI-Rider 工具体系预留。

### 2.0.0

- 进入正式规划阶段
- 明确版本定位：从单一工具升级为支持多模型、多 API、激活码机制和 Web 兼容的产品
- 完成 `2.x` 版本拆分原则和阶段子版本号建议
- 已完成 `2.0.0` PRD 初稿

### 2.0.1

- 规划中
- 目标方向：模型适配基础版

### 2.0.2

- 规划中
- 目标方向：多 API 接入版

### 2.0.3

- 规划中
- 目标方向：激活码闭环版

### 2.1.0

- 规划中
- 目标方向：产品表达升级版

### 2.1.1

- 规划中
- 目标方向：稳定性与体验补强版

### 2.2.0

- 工作台扩展版
- 新增模板中心页面，并支持模板一键回填主工作区
- 新增我的素材面板，支持本地素材上传、预览与回填
- 新增模型市场页面，支持按模型能力切换创作入口
- 统一仓库与运行时版本号为 `2.2.0`

### 2.3.0

- 激活码与注册码系统首版落地
- 新增首次启动激活引导页，默认先完成激活再进入工作台
- 新增微信领取体验码 / 正式注册码的产品路径
- 新增注册码按 `5 / 50 / 100 / 1000` 次分档
- 新增本地服务端激活、状态查询与扣次链路
- 新增注册码生成与管理 CLI 工具
- 统一仓库与运行时版本号为 `2.3.0`
