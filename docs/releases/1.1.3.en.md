# AI-Rider Video 1.1.3 Release Notes

[中文](./1.1.3.md) | **English**

## Release Position

`1.1.3` is the final stable release of AI-Rider Video before the `2.0.0` phase begins.

This release wraps up the full `1.x` line and introduces a formal mac packaging directory and naming convention.

## Highlights

- Stable Electron desktop packaging
- Unified product naming and icon system
- Archived `1.x` documentation structure
- Bilingual repository docs
- mac package version aligned to `1.1.3`

## Release Directory Convention

Local release directory:

```text
output/
  releases/
    1.1.3/
      mac/
        AI-Rider-Video-1.1.3-arm64.dmg
        AI-Rider-Video-1.1.3-arm64-mac.zip
        manifest.json
```

Notes:

- `output/releases/<version>/mac/` stores locally archived mac release artifacts
- artifact filenames use ASCII for easier cross-platform distribution and automation
- the user-facing app name still keeps the Chinese product name

## Naming Convention

- Product display name: `AI-Rider｜首尾帧生成视频工具`
- Repository version: `1.1.3`
- Artifact prefix: `AI-Rider-Video`

Artifacts:

- `AI-Rider-Video-1.1.3-arm64.dmg`
- `AI-Rider-Video-1.1.3-arm64-mac.zip`

## GitHub Note

The packaged installer files exceed the normal single-file size limit for a standard GitHub repository, so:

- code, docs, and release metadata should be pushed to the repository
- installer binaries should not be committed directly into git
- the better distribution path is GitHub Releases or external object storage
