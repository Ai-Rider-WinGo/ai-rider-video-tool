# AI-Rider Video 2.3.1 更新说明

## 版本定位

`2.3.1` 是在 `2.3.0` 激活码体系上线后的补充版本，重点不是产品功能继续扩展，而是把桌面端的自动打包与发布链路补齐。

## 本次更新

### 1. GitHub Actions 自动打包

- 新增 `build-desktop` workflow
- 支持自动构建：
  - `macOS`
  - `Windows`

### 2. Windows 打包支持

- 新增 `build:win` 脚本
- 新增 Windows `.ico` 图标
- 新增 NSIS 安装包配置

### 3. CI 构建修复

- 修复 GitHub Actions 在 `npm ci` 阶段被本地环境检查拦截的问题
- 保持本地环境检查继续严格执行
- 在 CI / 自动打包场景下自动跳过桌面依赖检查

## 一句话总结

**AI-Rider Video 2.3.1 = 在 2.3.0 激活体系基础上，补齐了桌面端 `mac + win` 的自动打包能力。**
