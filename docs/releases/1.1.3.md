# AI-Rider Video 1.1.3 发布说明

**中文** | [English](./1.1.3.en.md)

## 版本定位

`1.1.3` 是 AI-Rider Video 在 `2.0.0` 开始前的最终稳定发布版。

这一版承接了 `1.x` 的全部迭代成果，并首次整理出正式的 mac 发布目录和命名规范。

## 本版重点

- 桌面端 Electron 形态稳定可用
- 品牌名称与图标体系完成统一
- `1.x` 文档结构完成归档
- 中英文仓库文档可切换
- mac 安装包版本号统一为 `1.1.3`

## 发布目录规范

本地发布目录：

```text
output/
  releases/
    1.1.3/
      mac/
        AI-Rider-Video-1.1.3-arm64.dmg
        AI-Rider-Video-1.1.3-arm64-mac.zip
        manifest.json
```

说明：

- `output/releases/<version>/mac/` 用于保存本地归档的 mac 发布产物
- 文件名使用 ASCII，便于跨平台分发、上传和自动化处理
- 面向用户展示的应用名仍保留产品中文名

## 命名规范

- 产品显示名：`AI-Rider｜首尾帧生成视频工具`
- 仓库版本号：`1.1.3`
- 安装包文件名前缀：`AI-Rider-Video`

产物命名：

- `AI-Rider-Video-1.1.3-arm64.dmg`
- `AI-Rider-Video-1.1.3-arm64-mac.zip`

## GitHub 说明

本版安装包文件体积超过 GitHub 普通仓库单文件限制，因此：

- 代码、文档、版本信息可以正常推送到仓库
- 安装包本体不建议直接提交进 git 仓库
- 更合适的方式是后续发布到 GitHub Releases 或外部对象存储
