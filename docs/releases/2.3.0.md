# AI-Rider Video 2.3.0 更新说明

## 版本定位

`2.3.0` 是 AI-Rider Video 从“工作台扩展完成”走向“可控分发与激活使用”的第一版商业化基础版本。

这一版的核心不是继续加创作功能，而是补齐桌面端首次激活、注册码管理和按次使用的闭环。

## 本次更新

### 1. 首次启动激活引导

- 新增首次启动激活页
- 未激活时默认先进入激活引导，而不是直接进入工作台
- 页面内置微信二维码与激活说明

### 2. 微信领取注册码路径

- 明确产品路径为：安装完成 -> 添加微信 -> 获取注册码 -> 回到软件激活
- 适合当前阶段的体验码发放、手动筛选和后续续发

### 3. 注册码按次分档

- 支持 `5 / 50 / 100 / 1000` 次注册码档位
- 激活后显示剩余次数
- 当次数用完时，工作台生成入口自动锁定

### 4. 服务端激活与扣次

- 新增激活状态接口
- 新增激活接口
- 新增调试用扣次接口
- 创建任务前先检查激活状态
- 创建任务成功后再扣次，失败不扣次

### 5. 注册码管理工具

- 新增内部 CLI 工具，可直接生成和管理注册码
- 当前支持：
  - 生成注册码
  - 查询列表
  - 查看单码详情
  - 冻结
  - 作废
  - 重置设备绑定

## 当前边界

`2.3.0` 已经跑通激活码主链路，但仍属于第一版：

- 当前后台工具为 CLI，而不是完整 Web 后台
- 当前扣次与激活先跑在本地服务结构中，后续可迁移到远程服务
- 当前还未接入支付与自动发码商城

## 一句话总结

**AI-Rider Video 2.3.0 = 从一个可用的视频生成工作台，升级为一个支持首次激活、注册码按次使用、并可控分发的桌面产品。**
