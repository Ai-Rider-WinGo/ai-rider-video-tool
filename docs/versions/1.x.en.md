# AI-Rider 1.x Release Archive

[中文](./1.0.0.md) | **English**

## Definition

- Product name: `AI-Rider | First-to-Last Frame Video Tool`
- Version span: `1.0.0 - 1.1.3`
- Final stable release in this phase: `1.1.3`
- Phase goal: evolve the local web tool into a usable desktop product prototype, with branding, interaction polish, H5 adaptation, and launch assets.

## Initial Idea

1. Build a tool around the "first frame + last frame + prompt" workflow.
2. Make the local workflow usable first, then evolve into a desktop product.
3. Build for real creative work rather than just raw API invocation.

## 1.x Goals

1. Finish the desktop environment and runtime setup.
2. Establish AI-Rider naming and visual branding.
3. Improve the core generation experience, including sensible defaults, mode switching, prompt input, and task feedback.
4. Add multilingual and H5 support as a base for future expansion.
5. Prepare launch-ready copy and poster assets.

## Why the final state is `1.1.3`

1. The work did not land as a single delivery. It evolved through multiple clear functional and UX iterations.
2. The final state includes desktop packaging, branding, interaction polish, H5 adaptation, and launch assets.
3. Calling the final 1.x state `1.1.3` better reflects the actual product evolution and leaves room for a more meaningful `2.0.0`.
