# AI-Rider 1.x 版本档案

## 版本定义

- 产品名称：`AI-Rider｜首尾帧生成视频工具`
- 版本范围：`1.0.0 - 1.1.3`
- 当前收尾版本：`1.1.3`
- 阶段定位：从本地 Web 工具推进为可用的桌面端产品雏形，并完成品牌、交互、移动端适配和发布素材沉淀。

## 初始想法

1. 做一个围绕“首帧 + 尾帧 + 提示词”的视频生成工具。
2. 先把本地工作流跑通，再逐步向桌面端演进。
3. 工具不是只做接口调用，而是要贴近真实创作流程，减少反复切换页面、参数和文件夹的摩擦。

## 1.x 的核心目标

1. 完成桌面端环境和运行能力。
2. 确立 AI-Rider 的产品命名和视觉品牌。
3. 优化核心生成体验，包括默认参数、模式切换、提示词输入和任务状态反馈。
4. 做好多语言和 H5 适配，为后续扩展打基础。
5. 形成可发布的版本文案和海报素材。

## 版本拆分

### 1.0.0 基础工作流版本

- 跑通首帧、尾帧、提示词的本地 Web 工作流。
- 打通任务创建、轮询查询、结果下载。
- 确立 AI-Rider 的工具方向和第一版产品形态。

### 1.0.1 桌面环境版本

- 安装 Electron 依赖和桌面打包能力。
- 增加 Electron 桌面入口。
- 增加环境检查和安装说明。

### 1.0.2 品牌落地版本

- 产品名升级为 `AI-Rider｜首尾帧生成视频工具`。
- 接入 LOGO、favicon、桌面图标、窗口标题。
- 统一产品外显命名。

### 1.1.0 核心体验优化版本

- 增加镜头提示默认预设。
- 将额外参数折叠隐藏。

### 1.1.1 顶部工具条版本

- 增加 compact 顶栏。
- 整合语言、主题、下载目录、任务统计。
- 多轮优化标题栏高度、布局和滚动后的状态切换。

### 1.1.2 H5 与交互修正版本

- 完成移动端标题栏压缩和响应式适配。
- 修复 tooltip 越界问题。
- 优化配置项说明、开关和问号说明体验。

### 1.1.3 发布准备版本

- 输出 1.x 文案与海报。
- 补齐版本历史和结构化文档。
- 作为 `2.0.0` 规划前的稳定收口版本。

## 关键产品结论

1. AI-Rider 的第一阶段应该先稳住桌面端，而不是急于全端统一。
2. Electron 适合作为当前桌面端壳，后续 Web 和移动端可以共享部分逻辑，但不共用同一壳层。
3. 真实创作工具的竞争力不只在模型能力，也在参数组织、任务反馈、文件管理和交互细节。
4. 版本迭代应保留完整上下文，因此 `2.0.0` 不需要重新开一条对话，只需要在现有上下文上继续推进。

## 为什么将当前完成态定义为 1.1.3

1. 这一路不是一次性交付，而是经历了多轮清晰的功能和体验迭代。
2. 相比 `1.0.0`，当前状态已经包含桌面端、品牌、交互、H5、发布素材等多个层次的升级。
3. 用 `1.1.3` 作为 1.x 收尾版本，更符合真实的产品演进节奏，也方便 `2.0.0` 聚焦下一阶段能力跃迁。

## 对 2.0.0 的承接建议

1. 先定义 `2.0.0` 的目标，不要一开始同时铺太多方向。
2. 把产品线程和环境线程分开管理，但保留统一版本档案。
3. 以后每个版本都至少沉淀三份文档：
   - 版本目标
   - 版本迭代记录
   - 版本发布素材
